🐛 SORUN GİDERME / TROUBLESHOOTING:
================================================================================

❌ Setup wizard açılmıyor
   ✓ START_HERE.bat kullan
   ✓ python setup_wizard.py dene
   ✓ Python 3.8+ yüklü mü kontrol et

❌ "Python bulunamadı" hatası
   ✓ Python yükle: https://www.python.org/downloads/
   ✓ PATH'e eklendiğinden emin ol

❌ Klasör seçilemiyor
   ✓ Yönetici olarak çalıştır (sağ tık)
   ✓ Klasör yolunda Türkçe karakter olmasın

❌ Config.json kaydetmiyor
   ✓ Yazma izni ver
   ✓ Klasör mevcut mu kontrol et

⚠️ Sistem çok yavaş
   ✓ Worker sayısını azalt (2→1)
   ✓ Skip frames artır (5→10)
   ✓ Multi-frame kapat

⚠️ Çok fazla olay algılanıyor
   ✓ Motion threshold artır (1200→2000)
   ✓ Cooldown artır (8→15)

⚠️ Hiç olay algılanmıyor
   ✓ Motion threshold azalt (1200→800)
   ✓ Skip frames azalt (5→3)

✨ HIZLI İPUÇLARI / QUICK TIPS:
================================================================================

💡 İlk Kullanım:
   1. START_HERE.bat çalıştır
   2. Varsayılan ayarları kullan
   3. Bir test videosu çalıştır
   4. Sonuçlara göre optimize et

💡 Performans:
   • CPU yüksekse → Worker sayısını azalt
   • Bellek yüksekse → Multi-frame kapat
   • Disk doluyorsa → Frame kaydetmeyi kapat

💡 Kalite:
   • Detaylı analiz → Multi-frame aç + düşük skip
   • Hızlı tarama → Multi-frame kapat + yüksek skip
   • Gece videoları → Düşük motion threshold

💡 Bakım:
   • Raporları düzenli temizle
   • config.json'ı yedekle
   • Ayarları not et
