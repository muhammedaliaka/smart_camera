## Tam olarak ne değişmeli

**1) `lib/auth.ts` — `verifyToken`:** Token'ı imzalı üretin ve burada doğrulayın.
- Örnek: HMAC-SHA256 ve `.env` içinde bir `SESSION_SECRET`.
- Karşılaştırmada `crypto.timingSafeEqual` kullanın.
- İmza geçersizse `null` dönün.
- ID'yi yalnızca doğrulanmış token'dan okuyun.

**2) `app/dashboard/actions.ts`:**

```ts
"use server";

import { revalidatePath } from "next/cache";
import { query } from "@/lib/db";
import { getSessionUser } from "@/lib/auth";

export async function deleteInvoice(id: string) {
  const user = await getSessionUser();
  if (!user) throw new Error("unauthorized");
  if (typeof id !== "string" || id === "") throw new Error("invalid_id");

  const result = await query(
    "delete from invoices where id = $1 and owner_id = $2 returning id",
    [id, user.id],
  );
  if (result.rowCount === 0) throw new Error("not_found");

  revalidatePath("/dashboard");
}
```

- Kimlik kontrolü action'ın içinde.
- Sahiplik kontrolü SQL'in içinde (`owner_id = $2`). Başkasının faturası silinmez.
- Dönüş değeri yok, veri sızmaz.
- Proje kuralı gereği hata metinleri de config veya anahtar dosyasına gitmeli. Burada örnek için kısa tuttum.
