## 1. `deleteInvoice` herkese açık (kritik)
`app/dashboard/actions.ts:6` oturum kontrolü yapmıyor. `"use server"` dosyasındaki her fonksiyon herkese açık bir POST adresidir. Sayfadaki `redirect` bu fonksiyonu korumaz. Giriş yapmamış biri de, başkasının faturasının `id` değeriyle çağırabilir.

**Değişiklik** (`app/dashboard/actions.ts`):
```ts
"use server";

import { revalidatePath } from "next/cache";
import { getSessionUser } from "@/lib/auth";
import { query } from "@/lib/db";

export async function deleteInvoice(id: string) {
  const user = await getSessionUser();
  if (!user) throw new Error("Unauthorized");
  const result = await query(
    "delete from invoices where id = $1 and owner_id = $2 returning id",
    [id, user.id],
  );
  if (result.rowCount === 0) throw new Error("Not found");
  revalidatePath("/dashboard");
}
```
- `owner_id = $2` başkasının faturasını silmeyi engeller.
- `returning id` tüm satırı geri sızdırmaz.
- Admin silebilsin istiyorsan `user.role === "admin"` için ayrı bir dal ekle. Bunu sen karar ver.
