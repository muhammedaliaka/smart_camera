# Plan: Release hardening (Android + iOS)

Status: draft, Updated: 2026-10-26

## Repoda gördüklerim
- Dosyalar: `pubspec.yaml`, `analysis_options.yaml` (yalnızca `flutter_lints`), `lib/main.dart`.
- `android/`, `ios/`, `test/`, `pubspec.lock` yok. `.pusula/checks/pusula_check.py` de yok.
- `lib/main.dart:4`: `paymentApiKey` koda gömülü. `lib/main.dart:19`: anahtar `Authorization: Bearer` olarak gidiyor.
- `lib/main.dart:5`: `apiBase` da gömülü.
- Git geçmişi (`971fe23`) anahtar metnini tutuyor. Değer "not real" diyor.

## Goal
`demo_shop` için Android (`.aab`) ve iOS (`.ipa`) release sürümleri, obfuscation açık olarak derlenir. İkilide ödeme anahtarı olmaz. Analiz ve testler geçer. Her iddianın bu oturumdan çıktısı olur.

## Out of scope
Mağaza yayını (ayrı onay ister), backend'in yazılması, web/desktop, yeni özellik.

## Tasks

**Task 1. Taban ve platform klasörleri**
1. `flutter --version` ve `flutter doctor -v` çalıştır. Check: çıktı kaydedildi, eksikler (Android SDK, Xcode) listelendi.
2. `flutter pub get`. Check: `pubspec.lock` var, commit edildi.
3. Dokunulmamış kodda `flutter analyze`. Check: taban sonucu kaydedildi.
4. `flutter create --platforms=android,ios --project-name demo_shop .`. Check: `git diff` `lib/main.dart` ve `pubspec.yaml` için boş.
5. Gerçek application id / bundle id'yi yaz (kullanıcıdan gelir). Check: `grep` `com.example` bulmaz.

**Task 2. Anahtarı istemciden çıkar**
- Üretir: `AppConfig.apiBase` (`String`), `PaymentService(http.Client)` ile `Future<void> charge()`. 2xx dışında `PaymentException` fırlatır.
1. Önce Task 3 testlerini yaz, kırmızı gör.
2. İki yeni dosyayı yaz. İstek, güvenli depodaki kullanıcı oturum token'ını taşır. Check: `grep -rn "paymentApiKey\|demo-payment-key" lib/` boş döner.
3. `main.dart` servisi çağırır. Yükleniyor, başarı ve hata durumları eklenir. Metinler sabit dosyasına gider. Check: `flutter analyze --fatal-infos` temiz.
4. Anahtar bir gün gerçekse sağlayıcıda iptal et (rotate). Check: kullanıcı iptali onaylar.

Why code: ön ek bayrağının adı düzyazıyla sabitlenemez. Checked: UNVERIFIED.
```dart
static const apiBase = String.fromEnvironment('API_BASE');
```
`API_BASE` boşsa uygulama başlarken açıkça hata vermeli, sessiz kalmamalı.

**Task 3. Testler**
1. `payment_service_test.dart`: `charge posts to {apiBase}/charge`, `charge sends no static Authorization key`, `charge throws PaymentException on 500` (`MockClient`). Check: önce fail, Task 2'den sonra pass.
2. `shop_app_test.dart`: `Pay button shows loading then success`, `shows error text when service throws`. Check: `flutter test` yeşil.
3. `flutter test --coverage`. Check: gerçek oran raporlanır, hedef sözü verilmez.

**Task 4. Android release**
1. Upload keystore'u repo dışında üret. `android/key.properties` yerelde kalır. Check: `git check-ignore -v android/key.properties` eşleşir.
2. `flutter build appbundle --release --obfuscate --split-debug-info=build/symbols --dart-define=API_BASE=<url>`. Check: çıkış kodu 0, `.aab` var.
3. `build/symbols/` build numarasıyla repo dışında arşivlenir. Check: `flutter symbolize -i <trace> -d <symbols>` örnek izi okunur hale getirir.
4. Aynı bayraklarla release APK'yı cihaza kur. Check: Pay'in boş, yükleniyor, başarı, hata ekran görüntüleri, yazılı ölçütlere göre (`ui-acceptance`).

**Task 5. iOS release (yalnızca macOS)**
1. Xcode'da takım ve bundle id. Sertifikalar Keychain'de kalır. Check: `flutter build ios --release --no-codesign` geçer.
2. `flutter build ipa --release --obfuscate --split-debug-info=build/symbols --dart-define=API_BASE=<url>`. Check: `.ipa` var.
3. iOS sembollerini aynı şekilde arşivle ve `symbolize` ile dene.
4. Cihaz veya simülatörde dört durumun ekran görüntüsü.

**Task 6. Kanıt: üretilen dosyayı oku**

Why code: kontrolün kendisi bu komutlar. Checked: UNVERIFIED, çalıştırılmadı; dosya yolları sürüme göre değişir, önce `unzip -l` ile bul.
```bash
unzip -o app-release.aab -d build/aab_x
strings build/aab_x/base/lib/arm64-v8a/libapp.so | grep -c "ShopApp"          # obfuscate ile 0 beklenir
strings build/aab_x/base/lib/arm64-v8a/libapp.so | grep -c "demo-payment-key" # Task 2'den sonra 0 beklenir
```
1. Kontrol grubu: `--obfuscate` olmadan bir build al. İlk grep `ShopApp` bulmalı. Bulmazsa sıfır sonucun anlamı yok.
2. iOS'ta `App.framework/App` için tekrarla.
3. `pusula_check.py --only secrets,deps` varsa çalıştır. Yoksa `pubspec.lock` üzerinde `osv-scanner`. O da yoksa "not run" yaz.
4. Her çıktıyı `evidence.md`'ye yaz. Obfuscation'ın neyi saklamadığını da yaz: string'ler, enum adları, API URL'si, ağ trafiği.

- Conflicts: yok.

## Done when
- `flutter analyze --fatal-infos` temiz, `flutter test` geçer.
- Her iki release de cihazda/emülatörde çalıştı. Çalışmadıysa "not run" ve neden yazılır.
- Kontrol grubu ve grep kanıtı geçti, semboller arşivde, `evidence.md` dolu.
- UI durumlarının ekran görüntüleri var.

## Risks
1. Backend yok, anahtar taşınamaz. Önlem: Task 2'de dur, raporla. Anahtarı "şifreli" gömme.
2. Anahtar gerçekse git geçmişinde kalır. Önlem: sağlayıcıda iptal. Geçmişi yeniden yazmak ayrı onay ister.
3. Obfuscation `runtimeType.toString()` kullanan kodu bozar. Önlem: `lib/` içinde ara, release build'i çalıştır.
4. Semboller kaybolur, izler okunmaz. Önlem: build numarasıyla arşivle, `symbolize` dene.
5. Keystore veya sertifika kaybolur ya da sızar. Önlem: repo dışı yedek, `.gitignore`, hiçbir dosyaya yazma.
6. Bu Linux makinede iOS derlenemez. Önlem: Task 5'i "not run" yaz, iOS bitti deme.
7. Yanlış bundle id ilk yüklemede kilitlenir. Önlem: Task 1 adım 5'ten önce kullanıcı onaylar.
8. Testler yalnızca mock'a karşı geçer. Önlem: varsa staging sunucuda bir kez dene.
9. Flutter sürümü kayması bayrakları değiştirir. Önlem: sürümü `evidence.md`'ye yaz, fvm kullanılıyorsa sabitle.
10. Yeni lint sürümü eski kodu düşürür. Önlem: `pubspec.lock` commit'te, güncelleme bilinçli.
