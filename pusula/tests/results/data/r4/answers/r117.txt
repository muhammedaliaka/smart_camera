Bu komutları çalıştırmadım. Bu oturumda komut çalıştırma aracım ve elinizdeki dosyalar yok. Aşağıdakiler sizin makinenizde çalıştırmanız için yazıldı. Dosya adları ve kesit zamanları varsayımdır.

## 1. Kesitleri hazırla

Her kesiti aynı biçime getirin (1080p, 60 fps, ses yok). Süreleri toplamı 60 saniye olacak şekilde seçin. Örnek: 5 × 12 sn.

```bash
ffmpeg -ss 00:01:10 -t 12 -i clip1.mp4 -an -vf "scale=1920:1080:flags=lanczos,fps=60,format=yuv420p" -c:v libx264 -crf 14 -preset slow seg1.mp4
# clip2..clip5 için -ss ve dosya adını değiştirerek tekrarlayın: seg2.mp4 ... seg5.mp4
```

2560x1440 olarak kalmasını isterseniz `scale` satırını silin. 1080p, Steam için güvenli ve hafif seçenektir.

## 2. Birleştir, müziği ekle, dışa aktar

`list.txt` içeriği:
```
file 'seg1.mp4'
file 'seg2.mp4'
file 'seg3.mp4'
file 'seg4.mp4'
file 'seg5.mp4'
```

```bash
ffmpeg -f concat -safe 0 -i list.txt -i music.mp3 \
  -filter_complex "[1:a]atrim=0:60,asetpts=PTS-STARTPTS,afade=t=in:d=1,afade=t=out:st=57:d=3,loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -t 60 \
  -c:v libx264 -profile:v high -preset slow -crf 16 -maxrate 20M -bufsize 40M -pix_fmt yuv420p -r 60 \
  -c:a aac -b:a 320k -ar 48000 \
  -movflags +faststart trailer.mp4
```

Müzik 60 saniyeden kısaysa `-stream_loop -1` ekleyin: `-stream_loop -1 -i music.mp3`.

## 3. Steam'in istediği biçim

Aşağıdakiler hafızamdan. İnternetim olmadığı için güncel Steamworks belgesine karşı doğrulayamadım. Yüklemeden önce Steamworks'teki "Video" yönergesine bakın.

- **Kap:** MP4, H.264 (High profile), AAC ses.
- **Çözünürlük:** 16:9, en az 1080p önerilir. Siyah bant (letterbox) olmamalı.
- **Kare hızı:** 60 fps kabul edilir. 30 fps de olur.
- **İçerik:** Gerçek oynanış ağırlıklı olsun. Başa uzun logo koymayın. Sonuna yaş derecesi ya da fiyat bilgisi koymayın.

Steam yüklediğiniz dosyayı kendi yeniden kodlar. Kaynağı yüksek kalitede tutmak bu yüzden mantıklıdır.

## 4. Bittiğini kanıtlama

Şu komutu çalıştırın ve çıktısını bana yapıştırın:

```bash
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -show_entries stream=codec_name,profile,width,height,r_frame_rate,pix_fmt,sample_rate,channels \
  -of default=nw=1 trailer.mp4
```

Beklenen değerler:
- `duration` ≈ 60.0
- `codec_name=h264`, `profile=High`
- `width=1920`, `height=1080`, `r_frame_rate=60/1`, `pix_fmt=yuv420p`
- `codec_name=aac`, `sample_rate=48000`

Ses seviyesini ve kırpılma olup olmadığını da kontrol edin:

```bash
ffmpeg -i trailer.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -n 12
```

`I:` değeri yaklaşık −16 LUFS, `True peak` ise −1 dBTP veya altında olmalı.

Dosyanın bozuk olmadığından emin olmak için hata taraması yapın. Çıktı boşsa dosya temizdir:

```bash
ffmpeg -v error -i trailer.mp4 -f null - 
```

Son olarak dosyayı bir oynatıcıda baştan sona izleyin. Kesit geçişlerinde ve müziğin bitişinde ses atlaması olup olmadığına bakın. Bu kontrolü komutlar yapamaz.

Çıktıyı yapıştırırsanız değerleri yukarıdaki listeyle karşılaştırıp "tamam" ya da "şu düzeltilmeli" diye cevap veririm.
